SuperSmallModel

A GPT small enough to train at home.

Pure PyTorch, built from scratch — download weights and run, or train the whole stack on a laptop.

Download Run locally Train

Run

Clone, sync, generate from a checkpoint.

git clone https://github.com/AlexWoods1/SuperSmallModel.git
cd SuperSmallModel
uv sync
uv run stlm generate --checkpoint checkpoints/toy_cpu/ckpt_5000.pt --prompt "MENENIUS:" --max-tokens 200

What’s inside

~957k parameters · 4×128 GPT · byte-level BPE · hand-written causal attention · MIT

Train yourself

Smoke run in minutes; full toy config in hours on CPU. GPU is used automatically when CUDA is available. 

uv run stlm train --config configs/smoke.yaml
uv run stlm train --config configs/toy_cpu.yaml
